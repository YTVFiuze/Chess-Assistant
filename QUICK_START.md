# ⚡ Quick Start Guide

## 🎯 In 3 Minuti

### 1️⃣ Carica l'Estensione

```
1. Apri Chrome
2. Vai su chrome://extensions/
3. Attiva "Developer mode" (toggle alto-destra)
4. Clicca "Load unpacked"
5. Seleziona la cartella "extension" di questo progetto
```

### 2️⃣ Testa su Chess.com

```
1. Vai su https://www.chess.com/analysis
2. Clicca l'icona dell'estensione (♟️)
3. Clicca "Activate Assistant"
4. Aspetta 2-5 secondi
5. Vedrai frecce colorate!
```

### 3️⃣ Interpreta le Frecce

- **🟢 Verde** = Mossa migliore
- **🔵 Blu** = 2ª migliore
- **🟠 Arancione** = 3ª migliore
- **✨ Arancione brillante** = Mossa tattica speciale

---

## ⚠️ IMPORTANTE

**NON USARE in partite classificate!**

Violerebbe la Fair Play Policy di chess.com.

✅ **OK:** Analysis, training, studio
❌ **NO:** Rated games, tornei

## 🐛 Problemi?

### Frecce non appaiono?
1. Ricarica la pagina
2. Aspetta 5 secondi
3. Abilita debug mode

### Board non rilevata?
1. Vai su chess.com/analysis
2. Aspetta che la scacchiera carichi
3. Poi attiva l'estensione

### Errori?
1. Apri Console (F12)
2. Abilita debug mode in settings
3. Cerca errori rossi
